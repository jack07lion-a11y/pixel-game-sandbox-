# Pixel Game — Jasurbek & Jumanazar

Браузерда ўйналадиган пиксел-арт изометрик (2:1) очиқ дунё / sandbox ўйини. Битта `index.html` файл, ҳеч қандай қурилиш (build) керак эмас.

▶ **Ўйнаш:** GitHub Pages ёқилгандан кейин `https://<логин>.github.io/pixel-game/`

## Имкониятлар
- Горизонтал макет, ҳар қандай телефонга авто-мослашади
- Ҳар қандай ерни қазиш (Minecraft каби): юмшоқ/қаттиқ материаллар, рудалар, сув тошиши
- Уй қуриш таҳрирчиси: тепадан ва 3/4 3D кўриниш, кўп қаватли блоклар
- Қуёш системаси, 3 цивилизация, экосистема, об-ҳаво ва товуш

## Қисмлар
`index.html` — тайёр ўйин. `src/` — модуллар ва уларни қўшувчи скриптлар. `tests/` — Playwright синовлари. Давом эттириш учун `HANDOFF.md` ни ўқинг.
